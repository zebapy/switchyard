New script… — auto-detected command palette

No more manually picking a manifest. Switchyard walks the project, reads every package.json scripts block and Python pyproject.toml tasks ([tool.pdm.scripts] for PDM, [project.scripts] for uv), and offers them in one searchable menu grouped by project path. Each group header carries a runner badge (pnpm / pdm / uv), the project name + source file (sticky while scrolling); rows show the script name and its command, run with the right tool — pnpm run build, pdm run test, uv run scrape.
