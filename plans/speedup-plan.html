Switchyard — speed-up plan

20 findings across frontend, Rust backend, build/startup. Verified against code. Check items to mark done, add notes, copy results back.

Where the felt slowness lives — fix these 4 first

  1. Tab switch kills & respawns every terminal/agent — WorkspaceRoute.tsx:27 keys SplitPane on activeTab.id, so switching tabs unmounts the pane tree → pty_kill → lost scrollback + dead agents. Single biggest UX win.
  2. Agent-status ticks re-render the whole pane tree — SplitPane subscribes to entire panes/windows Maps; nothing is React.memo'd anywhere in the app.
  3. Blanket 15s poll over ALL projects × worktrees — ProjectTree.tsx:53 refreshes git + PR + per-worktree diff-stats for every project regardless of visibility/focus; each cycle reopens git repos, builds a fresh reqwest::Client, and storms Map-replacement re-renders.
  4. shiki shipped as full bundle — highlight.ts:2 imports barrel shiki → ~300 grammar chunks / ~10 MB emitted, oniguruma WASM eager in the 1.5 MB main chunk. App uses 1 theme.

Backend — Rust / Tauri

async GitHub/Linear commands do blocking git2 + keychain on the async runtime

Where github.rs:346 (get_pr_info), :178, :605, linear.rs:133,151. Real async fn commands call sync git2::Repository::open (repo_slug/current_branch) + debug-mode fs::read_to_string while holding a Mutex (token_store.rs:72) — all on Tokio workers. 15s poll × N projects multiplies it.

Fix Wrap sync git2 work in tokio::task::spawn_blocking; precompute owner/repo/branch once at top of each command.
Repo reopened 2× (get_pr_info) / 3× (github_pr_checks) per call

Where github.rs:96,188,256,357,467,502,544,608,660; linear.rs:104,135,159 — reqwest::Client::new() per call builds a fresh pool + TLS config, discarded after one request → new handshake every poll.

Fix One lazy shared client: static CLIENT: LazyLock<Client>, reuse everywhere.
pty_write holds the global instances Mutex across blocking write_all + flush
medbackendlock

Where pty.rs:406-416 — locks the single Mutex<HashMap> shared by all panes, then does I/O while holding it. A backpressured write blocks every other pane's write/resize/kill.

Fix Per-pane writer behind its own Mutex (or mpsc to a per-pane writer task); hold global lock only long enough to clone an Arc.
PTY reader emits a base64 event per read() — no batching
medbackendipc

Where pty.rs:367-400 — 64KiB buffer is good, but bursty output emits a separate base64-in-JSON event per read (+33% size, alloc+encode each). High emit frequency is a known Tauri IPC bottleneck.

Fix Coalesce reads in a ~5-16ms flush window (or until buffer full), emit once; consider raw bytes via channel instead of base64 JSON.
