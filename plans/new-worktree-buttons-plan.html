2The two flows

+ Quick worktree

  1. Hover project row → click +.
  2. Frontend generates a friendly adjective-noun name.
  3. Collision-check vs known worktree branches (from GitInfo.worktrees); retry on hit.
  4. Call existing createWorktree(repoPath, name) — no backend change.
  5. Auto-select → Workspace opens → default-agent Tab. No modal, ever.

⎐+ Create from…

  1. Hover project row → click second icon → modal opens.
  2. Pick a tab (Linear default). If provider not connected → Connect CTA.
  3. List loads (Linear: mine+active, with All toggle). Search filters in place.
  4. Click a row → worktree from that item's branch → modal closes.
  5. Auto-select → Workspace opens → default-agent Tab.
